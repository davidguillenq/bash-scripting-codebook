# Bash Scripting Codebook 🚀

Colección organizada de talleres prácticos y scripts de automatización en Bash creados durante el currículum de freeCodeCamp.

## Talleres Completados

### 01. Build a Boilerplate
- **Directorio:** `/01-build-a-boilerplate`
- **Conceptos:** Comandos básicos de consola, creación de estructuras de carpetas y navegación.

### 02. Build a Database of Video Game Characters
- **Directorio:** `/02-video-game-characters`
- **Conceptos:** Conexión e interacción entre scripts Bash y PostgreSQL.

### 03. Build Five Programs
- **Directorio:** `/03-build-five-programs`
- **Conceptos:** Variables, condicionales `if/else`, bucles `for`/`until`, arreglos e interacción mediante `read`.
- **Scripts incluidos:**
  - `questionnaire.sh`
  - `countdown.sh`
  - `bingo.sh`
  - `fortune.sh`
  - `five.sh`
